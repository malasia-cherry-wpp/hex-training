This Dataset (Firefly Watch Data 2018-2023) is from Mass Audubon 501c3.  

Formally referred to as the Firefly Watch project, this was a community science project where volunteers across North America tracked the geographic distribution, seasonal timing, and abundance of fireflies.  

This dataset is relevant to The Firefly Spies vehicle TV Show project because (1) it asks the question: how many North Americans have spotted fireflies from 2018 to 2023 and (2) it collects information of the environment in which fireflies were spotted including but not limited to longitude, latitude, precipitation, presence of artificial light, etcetera.  

We can use this dataset to advise our generative environment design in Adobe Firefly; replicating observed environments that children (ages 3 - 8) already associate with the firefly species.  

I plan to use this data for the following discovery: 

 When are most fireflies visible?  

I’ll use the Number of Fireflies Spotted column and the average of the Observation Start Time and Observation End Time columns.
